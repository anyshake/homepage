The NTP server shares Observer's internal time source over UDP. It does not set the host operating system clock and is separate from the NTP client configured in `config.json`.

| Setting | Key | Default | Meaning |
| --- | --- | --- | --- |
| Enable | `enabled` | `false` | Enable NTP serving. |
| Listen Host | `listen_host` | `0.0.0.0` | Bind address. |
| Listen Port | `listen_port` | `123` | UDP port. |
| Delay Control | `delay_control` | `0` | Add a fixed signed correction in microseconds. |

Before enabling, verify the station's time source and check whether another daemon already owns UDP 123. Binding a privileged port on Linux requires `CAP_NET_BIND_SERVICE` or equivalent privileges; the unit generated by the installer grants this capability to its dedicated account.

The implementation reports stratum 1 and reference ID `GNSS`. These advertised values are fixed and do not by themselves verify a live GNSS lock or measured accuracy. USB buffering, serial transmission, and network path asymmetry still affect timing. Calibrate any fixed delay against an independent trusted reference.

Use a trusted LAN or private VPN and allow UDP traffic to the configured port. See [Serve as Stratum 1 NTP Server](../../applications/serve-as-stratum-1-ntp.md) for setup and client checks.
