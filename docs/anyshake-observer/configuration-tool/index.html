Configuration Tool

Observer reads its base configuration from JSON. AnyShake Prisma provides a visual editor, live JSON preview, and download button. This reference describes fields read by Observer 4.9.0; check generated output against it when using another Prisma version.

Download config.json and pass it with observer -config /path/to/config.json. File changes require restarting Observer. Station and optional service settings are stored in the database and managed through the web interface.

Complete Example​

This example uses an E-C111G over serial and persistent SQLite storage. Replace coordinates, connection, and paths for your station. Create the database's parent directory and make it writable by the running account.

{
    "location": {
        "latitude": 25.033,
        "longitude": 121.5654,
        "elevation": 10
    },
    "hardware": {
        "endpoint": "serial:///dev/ttyUSB0?baudrate=57600",
        "protocol": "v3",
        "model": "E-C111G",
        "timeout": 5
    },
    "ntpclient": {
        "pool": [
            "ntp://time.mit.edu:123",
            "ntp://ntp1.lsu.edu:123",
            "ntp://ntp1.tamu.edu:123",
            "ntp://ntp1.cs.princeton.edu:123",
            "ntp://ntp.illinois.edu:123"
        ],
        "timeout": 5,
        "retry": 5
    },
    "database": {
        "endpoint": "sqlite://",
        "username": "",
        "password": "",
        "database": "/var/lib/observer/observer.db",
        "prefix": "as_",
        "timeout": 5
    },
    "server": {
        "listen": "127.0.0.1:8073",
        "debug": false,
        "cors": false
    },
    "logger": {
        "level": "info",
        "rotation": 5,
        "lifecycle": 3,
        "size": 0,
        "path": ""
    }
}

These are example values, not defaults applied to omitted fields. Provide all sections and required values explicitly. Relative database, log, custom metadata, and service paths resolve from the working directory, not the location of config.json or the executable.

Location​

FieldMeaning
location.latitudeFallback latitude in degrees, -90 to 90.
location.longitudeFallback longitude in degrees, -180 to 180.
location.elevationFallback elevation in metres.

GNSS position replaces fallback coordinates when available. Coordinates affect metadata and estimated seismic arrival times. General dashboard views round coordinates for non-administrators; exported metadata and integrations may include the actual location, so review them before sharing.

Hardware​

FieldMeaning
hardware.endpointRequired transport URL: serial:// or tcp://.
hardware.protocolv1, v2, or v3; legacy aliases v1. Match the firmware protocol.
hardware.modelBuilt-in metadata model or path to a custom metadata directory.
hardware.timeoutRead timeout in seconds; zero uses the transport's five-second default.

Typical endpoints:

serial:///dev/ttyUSB0?baudrate=57600
serial:///dev/serial/by-id/your-device?baudrate=57600
serial://COM3?baudrate=57600
tcp://192.168.1.50:30000

The serial baud rate is required and must match the device. Inspect /dev/serial/by-id/ or kernel messages on Linux, or Device Manager on Windows. Only one application should open a serial device at a time. TCP transport connects through a serial-to-network bridge. GNSS is recommended for TCP because network latency affects software-derived timestamps.

Protocol v1 is the legacy three-channel format, v2 is used by E-D001, and v3 supports newer devices and up to eight channel slots. Check firmware rather than choosing solely by Observer version.

Built-in metadata currently includes E-D001, E-C111G, E-C121G, and E-C131G. Custom directories require attributes.yaml, stationxml.tpl, and seiscomp.tpl; follow the source metadata library reference. Use an instrument response matching your hardware.

NTP Client​

FieldMeaning
ntpclient.poolArray of NTP URLs, such as ntp://ntp.nict.jp:123.
ntpclient.timeoutRequest timeout in seconds.
ntpclient.retryBounds additional batches using other endpoints after failures or disagreement.

ntpclient.endpoint is deprecated since 4.2.0. Observer migrates it in memory only if pool is empty; update the file to use an array.

Observer maintains an internal time source without setting the host clock. GNSS-derived timestamps take priority when available. NTP synchronization validates replies, compares agreeing sources, and periodically refreshes source selection. Configure several independent reachable servers; three or more help reject an incorrect clock. Five healthy sources meet the routine preferred-source target. Proximity, network asymmetry, and server quality affect accuracy; ping latency alone is insufficient.

NTP needs outbound UDP, usually port 123. An initial required synchronization failure can prevent startup. One usable source is accepted for availability but cannot be cross-checked. Failed later measurements leave the existing clock correction in place. See the source NTP client reference for polling and retries.

Database​

FieldMeaning
database.endpointEngine URL; include host and port for remote engines.
database.username / passwordRemote database credentials.
database.databaseSQLite file path or remote database name. Required.
database.prefixTable prefix; release example: as_. Keep stable after initialization.
database.timeoutConnection timeout in seconds.
EngineEndpoint exampledatabase.database example
SQLitesqlite:// or sqlite3:///var/lib/observer/observer.db
MySQL / MariaDBmysql://127.0.0.1:3306 or mariadb://127.0.0.1:3306observer
PostgreSQLpostgres://127.0.0.1:5432 or postgresql://127.0.0.1:5432observer
SQL Serversqlserver://127.0.0.1:1433 or mssql://127.0.0.1:1433observer

Driver availability varies by build target. An unsupported engine error lists available engines. SQLite needs a writable file and parent directory for journal/WAL files. Remote databases must already exist, with permissions to create and migrate tables. Use a dedicated database account.

The release example's /tmp/observer.db is temporary; change it before deployment. Changing the database path, name, or table prefix can select an empty database and appear to reset users, settings, and history. Retention is configured in Archiver Service, independently of MiniSEED retention.

Web Server​

FieldMeaning
server.listenRequired host:port, e.g. 127.0.0.1:8073, 0.0.0.0:8073, or [::]:8073.
server.debugEnables GraphQL Playground at /api/graphql and pprof on localhost:6060. Keep disabled for normal operation.
server.corsAllows cross-origin API requests when true. Authentication remains required.

The executable serves HTTP. Use an HTTPS reverse proxy for public access or Tailscale for private remote access. A proxy must forward WebSocket upgrades for live waveforms and permit streaming notification responses. Bind to loopback if only a local proxy or embedded Tailscale needs access.

Logger​

FieldMeaning
logger.levelinfo, warn, or error. Required.
logger.rotationMaximum old files retained; zero removes the count limit.
logger.lifecycleMaximum age of old files in days; zero removes the age limit.
logger.sizeMaximum file size in megabytes; zero uses the logging library's 100 MB default.
logger.pathOutput file path; empty disables file logging. Console output remains.

Old logs are compressed. Count and age limits are independent; zero does not disable size-based rotation. For systemd/Docker, use "path": "" and read journal/container logs. For file logging in this version, create the parent directory and an empty writable regular log file first: current startup code attempts to create a directory at a nonexistent configured log path.

Restrict config.json access to the process account and administrators because it may contain database credentials.
